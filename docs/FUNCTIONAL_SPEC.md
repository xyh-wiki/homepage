# 功能规格

- 版本：1.2
- 日期：2026-08-31
- 读者：产品维护者、开发者和内容维护者

## 1. 产品定义

xyh.wiki Homepage 是公开的在线工具与项目目录，同时提供围绕常见工具任务的原创实践指南。访客无需了解项目的部署位置，可以按名称、用途和分类找到目标入口，也可以先阅读方法说明再选择工具。

公开页面只展示访客选择项目所需的信息。内部主机、端口、容器、维护日期、监控信息和尚未启用的产品计划均不进入公开 HTML。

## 2. 角色与权限

| 角色 | 浏览公开页面 | 搜索筛选 | 打开公开项目 | 打开登录入口 | 修改目录 |
|---|---:|---:|---:|---:|---:|
| 访客 | 是 | 是 | 是 | 仅可到登录或授权入口 | 否 |
| 搜索引擎 | 是 | 不适用 | 通过链接发现 | 说明页按配置 `noindex` | 否 |
| 维护者 | 是 | 是 | 是 | 是 | 通过 Git 修改并评审发布 |

首页没有账户、租户、写接口和数据库。

## 3. 数据模型

### 3.1 分类

分类维护在 `data/catalog.json`，字段包括：

- `id`：稳定标识，用于筛选。
- `label`：详情页和项目列表显示名称。
- `filterLabel`：首页筛选按钮的短名称。

新增分类后，筛选按钮由构建器自动生成。

### 3.2 访问类型

访问类型也维护在 `data/catalog.json`：

- `label`：详情页显示名称。
- `listLabel`：首页项目列表中的简短标记；空字符串表示不显示。
- `indexable`：详情页是否允许进入 Sitemap。
- `boundary`：该访问类型共用的使用说明。

当前类型包括公开访问、公开演示和需要登录。

### 3.3 项目

项目维护在 `data/services.json`。主要字段：

| 字段 | 约束 |
|---|---|
| `slug` | 唯一、小写短横线，用于稳定 URL |
| `name` | 真实项目名称，全局唯一 |
| `url` | `https://*.xyh.wiki/`，无显式端口，全局唯一 |
| `category` | 必须引用现有分类 |
| `availability` | 必须引用现有访问类型 |
| `host` | 仅内部维护使用，禁止写入公开页面 |
| `summary` | 一句话说明真实用途 |
| `features` | 至少 3 项真实能力 |
| `keywords` | 站内搜索词，不生成 meta keywords |
| `language` | 项目界面语言 |
| `audience` | 适用用户和任务 |
| `steps` | 至少 3 个真实使用步骤 |
| `guidance` | 项目专属使用建议 |

新增同类项目只需增加一条数据，不需要修改模板或构建逻辑。

### 3.3 实践指南

实践指南维护在 `src/content/*.md`，每篇围绕一个真实任务提供背景、核对步骤、限制和工具链接。指南必须能够脱离广告和目标工具独立阅读，不得只扩写关键词或重复项目摘要。

## 4. 核心用例

### 4.1 浏览目录

1. 访客从首页了解站点用途。
2. 可先从精选项目入口选择常用或重点项目。
3. 查看项目名称、摘要、分类和必要的访问标记。
4. 打开详情页了解功能与使用说明。
5. 从详情页前往目标项目。

项目列表采用连续行式布局，不使用卡片阵列、伪指标或装饰性大屏。

### 4.2 搜索与筛选

- 搜索名称、摘要、能力和关键词，不区分大小写。
- 搜索和分类条件同时生效。
- 搜索在浏览器本地执行，不发送输入内容。
- 首页搜索框支持 `/` 键快速聚焦，并提供清除搜索操作。
- 结果为零时显示明确空状态。
- 空状态提供清除搜索和分类条件的操作。
- 分类筛选项根据分类数据自动生成。
- 当前分类按钮通过 `aria-pressed` 暴露选中状态。

### 4.3 阅读项目说明

每页展示：

- 项目名称和摘要；
- 真实能力；
- 访问方式；
- 界面语言；
- 通用访问说明；
- 项目专属使用建议；
- 打开项目的 HTTPS 链接。

页面不得展示 `host` 或其他内部部署字段。

### 4.4 阅读站点页面

关于、使用说明、隐私、条款、服务说明和联系页面可从页眉、首页或页脚到达。实践指南从首页和使用说明页可达。正文只描述当前站点事实，不向访客展示内部规划。

## 5. 页面状态

- 加载：静态 HTML 立即显示，不展示伪进度。
- 广告脚本：只有原创实践指南异步加载 Google AdSense；首页、目录、项目说明、政策页和 404 页面不加载广告脚本，脚本或广告请求失败不得阻断正文。
- 隐私政策提供 Google 广告设置和 YourAdChoices 入口；EEA、英国和瑞士的同意收集由 AdSense 后台的 Google Privacy & Messaging 或认证 CMP 配置负责。
- 空结果：说明没有匹配项，建议清除搜索或选择全部。
- 404：返回真实 404 状态并 `noindex`。
- JavaScript 禁用：筛选不可用，但所有项目和链接仍然可见。
- 移动端导航：关于和联系入口收纳在可展开的“更多”菜单中。
- 移动端：项目摘要、分类和访问标记完整保留。
- 指南页：显示原创实践指南标记、更新时间、完整正文和至少一个相关工具或政策链接。

## 6. 可扩展性要求

- 分类、访问类型和项目内容使用数据文件维护。
- 构建器不得包含按项目 slug 编写的文案映射。
- 模板不得硬编码分类按钮。
- 新增项目自动生成详情页、结构化数据和 Sitemap 状态。
- 构建期校验重复 slug、名称、URL、未知引用、字段缺失和 URL 安全性。
- 测试统计生成的项目行数，并验证每个分类筛选项存在。

## 7. 验收

验收以生成文件、自动化测试、容器健康、HTTP 状态和桌面/移动端浏览器结果为证据。生产发布、外部抓取和真实用户性能属于独立上线验收，未执行时不得表述为通过。
