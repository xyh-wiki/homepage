# 功能规格

- 版本：1.2
- 日期：2026-08-31
- 读者：产品维护者、开发者和内容维护者

## 1. 产品定义

xyh.wiki Homepage 是内容优先的工具实践与开发笔记站点。访客可以阅读围绕文件处理、文本清理、浏览器隐私和开源项目评估的原创指南，并在需要时访问文章中提到的工具。

公开页面优先展示能够独立解决问题的文章正文。内部主机、端口、容器、监控信息和尚未启用的产品计划均不进入公开 HTML。

## 2. 角色与权限

| 角色 | 浏览公开页面 | 选择文章主题 | 打开相关工具 | 打开登录入口 | 修改内容 |
|---|---:|---:|---:|---:|---:|
| 访客 | 是 | 不适用 | 通过文章上下文访问 | 仅可到登录或授权入口 | 否 |
| 搜索引擎 | 是 | 不适用 | 只收录原创指南和站点说明 | 参考页按配置 `noindex` | 否 |
| 维护者 | 是 | 不适用 | 是 | 是 | 通过 Git 修改并评审发布 |

首页没有账户、租户、写接口和数据库。

## 3. 数据模型

### 3.1 分类

分类维护在 `data/catalog.json`，字段包括：

- `id`：稳定标识，用于工具参考页分类。
- `label`：工具参考页显示名称。
- `filterLabel`：保留的短分类名称。

新增分类后，工具参考页可以复用分类名称；分类不会生成首页筛选器。

### 3.2 访问类型

访问类型也维护在 `data/catalog.json`：

- `label`：详情页显示名称。
- `listLabel`：工具参考页中的简短标记；空字符串表示不显示。
- `indexable`：历史字段，当前参考页统一不进入 Sitemap。
- `boundary`：该访问类型共用的使用说明。

当前类型包括公开访问、公开演示和需要登录。

### 3.3 项目

项目维护在 `data/services.json`。主要字段：

| 字段 | 约束 |
|---|---|
| `slug` | 唯一、小写短横线，用于稳定 URL |
| `name` | 真实项目名称，全局唯一 |
| `url` | `https://*.xyh.wiki/`，无显式端口，全局唯一 |
| `category` | 必须引用现有分类 |
| `availability` | 必须引用现有访问类型 |
| `host` | 仅内部维护使用，禁止写入公开页面 |
| `summary` | 一句话说明真实用途 |
| `features` | 至少 3 项真实能力 |
| `keywords` | 站内搜索词，不生成 meta keywords |
| `language` | 项目界面语言 |
| `audience` | 适用用户和任务 |
| `steps` | 至少 3 个真实使用步骤 |
| `guidance` | 项目专属使用建议 |

新增同类项目只需增加一条数据，不需要修改模板或构建逻辑。

### 3.3 实践指南

实践指南维护在 `src/content/*.md`，每篇围绕一个真实任务提供背景、核对步骤、限制和工具链接。指南必须能够脱离广告和目标工具独立阅读，不得只扩写关键词或重复项目摘要。

## 4. 核心用例

### 4.1 阅读实践指南

1. 访客从首页了解站点主题和内容原则。
2. 从实践指南列表选择与当前问题相关的文章。
3. 阅读背景、步骤、限制、截图和核对方法。
4. 根据文章上下文决定是否访问相关工具。
5. 通过联系页面反馈过时或不准确的内容。

### 4.2 阅读工具参考页

每页展示：

- 项目名称和摘要；
- 实际界面截图及采集日期；
- 适用人群和任务；
- 真实能力；
- 可重复的开始步骤；
- 访问方式；
- 界面语言；
- 通用访问说明；
- 项目专属使用建议；
- 打开项目的 HTTPS 链接。

页面不得展示 `host` 或其他内部部署字段。

### 4.3 阅读站点页面

关于、使用说明、隐私、条款、服务说明和联系页面可从页眉、首页或页脚到达。实践指南从首页和使用说明页可达。正文只描述当前站点事实，不向访客展示内部规划。

## 5. 页面状态

- 加载：静态 HTML 立即显示，不展示伪进度。
- 广告脚本：只有原创实践指南异步加载 Google AdSense；首页、目录、项目说明、政策页和 404 页面不加载广告脚本，脚本或广告请求失败不得阻断正文。
- 隐私政策提供 Google 广告设置和 YourAdChoices 入口；EEA、英国和瑞士的同意收集由 AdSense 后台的 Google Privacy & Messaging 或认证 CMP 配置负责。
- 404：返回真实 404 状态并 `noindex`。
- JavaScript 禁用：文章正文、截图替代文本和外部工具链接仍然可见。
- 移动端导航：关于和联系入口收纳在可展开的“更多”菜单中。
- 移动端：文章正文、截图、标题层级和外部链接完整保留。
- 指南页：显示原创实践指南标记、更新时间、完整正文和至少一个相关工具或政策链接。

## 6. 可扩展性要求

- 分类、访问类型和项目内容使用数据文件维护。
- 构建器允许为文章声明标题、描述、更新时间和截图元数据，但正文必须维护在独立 Markdown 文件中。
- 新增指南自动生成文章页、结构化数据和 Sitemap 条目。
- 工具参考页统一生成 `noindex,follow`，不进入 Sitemap。
- 构建期校验重复 slug、名称、URL、未知引用、字段缺失和 URL 安全性。
- 测试验证指南页、截图、结构化数据、文章链接和参考页索引策略。

## 7. 验收

验收以生成文件、自动化测试、容器健康、HTTP 状态和桌面/移动端浏览器结果为证据。生产发布、外部抓取和真实用户性能属于独立上线验收，未执行时不得表述为通过。
