# 功能规格

- 版本：1.0
- 代码基线：初始正式版
- 日期：2026-08-12
- 读者：产品维护者、开发者、SEO/广告审核准备人员

## 1. 产品定义

xyh.wiki Homepage 是公开服务目录与内容入口。它整合两台正式主机上适合用户直接访问的服务，但不暴露基础设施、内部 API、代理订阅、数据库、缓存、监控或管理面。

## 2. 角色与权限

| 角色 | 浏览公开页面 | 搜索筛选 | 打开公开服务 | 打开受限服务 | 修改目录 |
|---|---:|---:|---:|---:|---:|
| 访客 | 是 | 是 | 是 | 仅可到登录/授权入口 | 否 |
| 搜索引擎 | 是 | 不适用 | 通过链接发现 | 说明页 `noindex` | 否 |
| 维护者 | 是 | 是 | 是 | 是 | 通过 Git 修改并评审发布 |

首页没有账户、租户、写接口和数据库。

## 3. 服务状态

- `public`：无需登录的正式公开服务。
- `public-demo`：无需登录的演示服务，不接受秘密或生产材料。
- `private`：需要登录或持有者授权；对应说明页 `noindex`。

状态只表示访问边界，不是实时健康状态。

## 4. 核心用例

### 4.1 浏览目录

前置条件：页面成功加载。

主流程：

1. 访客阅读首页定位说明。
2. 向下进入服务目录。
3. 查看名称、类别、摘要、关键能力和访问状态。
4. 打开服务说明页或直接继续浏览。

失败与恢复：静态资源失败时，服务链接和正文仍保留在 HTML；CSS 失败不应影响语义顺序。

### 4.2 搜索与筛选

输入：任意文本，或媒体创作、文本处理、开发者、个人服务之一。

规则：

- 搜索名称、摘要、能力和关键词，不区分大小写。
- 搜索与分类条件同时生效。
- 搜索不发送网络请求，不持久化。
- 结果为零时显示明确空状态。

### 4.3 阅读服务说明

每页展示真实摘要、三个能力点、访问和数据边界、界面语言、维护节点、核对日期和使用建议。主要动作打开 HTTPS 子域名；受限服务不得声称其内部内容公开。

### 4.4 阅读政策与指南

关于、指南、隐私、条款、广告披露、服务范围和联系页面均可从页脚到达。文案不得把计划中的 AdSense 描述为已启用。

## 5. 内容字段

| 字段 | 约束 |
|---|---|
| `slug` | 唯一、小写短横线、用于稳定 URL |
| `name` | 1–80 字符，真实产品名 |
| `url` | `https://*.xyh.wiki/`，无显式端口 |
| `category` | `media` / `writing` / `developer` / `personal` |
| `availability` | `public` / `public-demo` / `private` |
| `host` | `miles-01` / `xyh-dep`，仅维护事实 |
| `summary` | 具体描述用途，不含伪指标和空泛营销词 |
| `features` | 至少 3 项真实能力 |
| `keywords` | 仅用于站内筛选，不生成 meta keywords |

## 6. 页面状态

- 加载：静态 HTML 立即显示，不展示伪进度。
- 空结果：说明没有匹配项，建议清除搜索或选择全部。
- 404：真实 404 状态并 `noindex`，提供返回首页和指南的路径。
- JavaScript 禁用：筛选不可用，但全部服务与链接可见。
- 移动端：列表变为连续内容，不隐藏摘要与状态。

## 7. 广告规则

- 初始正式版不加载广告网络。
- 仅在配置真实 `ADSENSE_CLIENT` 后加载脚本。
- 仅在配置真实 `ADSENSE_PUBLISHER_ID` 后生成 `ads.txt`。
- 广告不靠近“打开服务”按钮，不遮挡内容，不制造误点击。
- 受限服务页、404 和没有实质正文的页面不放广告。
- 启用前必须完成隐私更新、CMP 配置、地区同意测试和性能复验。

## 8. 验收

验收以生成文件、自动化测试、容器健康、HTTP 状态、渲染后 HTML 和移动端截图为证据。Search Console、AdSense 审核和真实用户 Core Web Vitals 属于上线后的外部验收，未执行时不得表述为通过。
