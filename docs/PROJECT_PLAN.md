# xyh.wiki Homepage 项目规划

- 文档版本：1.1
- 更新日期：2026-08-25
- 交付类型：正式公共网站
- 正式入口：`https://xyh.wiki/`

## 1. 产品定位

Homepage 是 xyh.wiki 下在线工具与公开项目的统一入口。访客需要知道项目能做什么、是否需要登录以及如何进入，不需要了解项目运行在哪台机器或由何种基础设施承载。

## 2. 1.1 改版背景

初始版本存在以下问题：

- 首页直接展示内部主机名和运行节点数量。
- 页面把未来商业计划、审核准备和占位区域写给普通访客。
- 米白、深绿、陶土橙、巨型衬线标题和指标栏形成明显的模板感。
- 大量“眉题 + 大标题 + 描述”重复结构影响真实产品感。
- 分类按钮和项目专属建议写死在模板或构建脚本中，不利于继续增加项目。

1.1 改版将这些实现视为产品问题，而不是仅做文案替换。

## 3. 产品目标

1. 建立自然、克制、正式的工具目录。
2. 让访客通过搜索、分类和摘要快速找到项目。
3. 公开页面只展示访客需要的信息。
4. 为每个项目提供完整、原创的说明页。
5. 保持可抓取、可分享、移动端可用和轻量性能。
6. 让后续增加项目主要通过数据配置完成，而不是不断修改模板。

## 4. 非目标

- 不显示内部主机、IP、端口、容器、监控和实时运行指标。
- 不把登录后的内容或管理入口包装成公开内容。
- 不在公开页面展示尚未启用的功能和商业计划。
- 不批量制造薄内容、伪 FAQ、虚构评价或用户指标。
- 本次本地改版不自动提交、推送或部署。

## 5. 信息架构

### 可索引

- `/`
- `/guide/`
- `/about/`
- `/privacy/`
- `/terms/`
- `/contact/`
- `/status/`
- 访问类型设置为 `indexable: true` 的项目详情页

### 禁止索引

- 访问类型设置为 `indexable: false` 的项目详情页
- `/404.html`

### 历史 URL

- `/advertising/`：永久跳转至 `/privacy/`

## 6. 页面设计

### 首页

1. 简洁顶栏：站点名称、项目、使用说明，以及收纳关于和联系的“更多”菜单。
2. 简短站点介绍和“浏览全部项目”入口，不使用口号式营销文案。
3. 数据驱动的精选项目列表。
4. 搜索、可清除输入和数据驱动的分类筛选。
5. 连续项目列表：名称、用途、分类、必要的访问标记。
6. 普通说明区：文件与隐私、结果核对、登录入口。
7. 简洁页脚：关于、说明、隐私、条款、联系。

移动端筛选栏支持横向滚动，筛选按钮使用 `aria-pressed` 表示当前状态，搜索框支持 `/` 快捷键。

### 项目详情

- 项目名称与摘要；
- 主要功能；
- 使用说明；
- 项目专属建议；
- 分类、访问方式与语言；
- 打开项目和返回目录。

### 文章页

- 单一正文列和简洁相关链接；
- 不使用眉题、装饰性序号或超大标题；
- 不解释内部部署和未来规划。

## 7. 视觉方向

- 白色和浅灰背景；
- 近黑正文、灰色辅助文字；
- 单一克制蓝色强调；
- 系统无衬线字体；
- 无渐变、无阴影、无大圆角；
- 无巨型 Hero、衬线标题和大数字指标栏；
- 项目采用接近索引或表格的连续列表；
- 完整视口背景和最大约 1240px 的内容区域。

## 8. 可扩展性

- `data/catalog.json` 维护分类和访问类型。
- `data/services.json` 维护项目内容。
- 分类筛选按钮自动生成。
- 项目详情页、结构化数据和 Sitemap 自动生成。
- 项目专属建议随项目数据维护，不在构建脚本中按 slug 映射。
- 构建期校验字段、引用、唯一性和 URL。
- 自动化测试验证分类、项目数量、SEO 和公开信息边界。

## 9. SEO

SEO 直接适用：

- 正文存在于初始 HTML；
- 每页唯一 title、description、H1 和 canonical；
- JSON-LD 与可见内容一致；
- Sitemap 根据访问类型自动生成；
- 非公开项目页 `noindex`；
- 真实 404；
- 历史 URL 使用永久跳转；
- 移动端无横向溢出；
- 不生成伪指标、重复关键词页或不可验证声明。

## 10. 验收标准

### 功能

- 所有项目均由数据生成并可从首页发现。
- 搜索、分类组合筛选和空结果状态可用。
- 新增现有分类项目无需修改模板。
- 新增分类无需修改首页模板。

### 公开边界

生成的全部 HTML 不包含：

- 内部主机名；
- 运行节点或维护节点；
- 内部端口和 IP；
- 维护核对日期；
- 未启用的商业计划和占位文案。

### 视觉和可访问性

- 1440px 桌面和 390px 移动端布局自然。
- 无横向滚动。
- 键盘焦点可见。
- 禁用 JavaScript 仍能浏览全部项目。
- 搜索与筛选在本地完成。

### 工程

- `npm run test` 通过。
- Node 语法和 JSON 校验通过。
- `git diff --check` 通过。
- Docker Compose 配置有效。
- 容器健康、关键路径状态和永久跳转正确。

## 11. 发布边界

本地改版完成不等于已经上线。只有完成评审、Git 提交、推送和 Dokploy 发布后，正式站点才会更新。发布前记录上一版本，出现健康、TLS、导航、SEO 或信息泄露问题时回滚。
