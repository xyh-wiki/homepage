# 如何选择合适的工具

这个目录按任务而不是技术栈组织服务。下面的选择方法可以减少在多个子域名之间来回尝试。针对常见任务，首页还整理了几篇更详细的实践指南，包含检查步骤、限制和结果核对方法。

## 转换音频或视频

需要改变文件格式、统一输出参数或批量处理时，使用 Audio Convert。它的核心处理发生在浏览器本地，适合不希望上传媒体文件的场景。开始前仍应确认浏览器内存和设备性能足以处理大文件，并保留原始文件。

## 清理或检查文本

需要整理文本、格式化结构化内容或执行常见编辑任务时，使用 EditText Lab。它把多个小型工具放在同一个站点中，适合临时处理内容。对于包含密码、令牌或客户数据的文本，仍应先确认目标工具的具体处理方式，并遵守所在组织的数据规则。

## 阅读开源趋势

需要快速了解近期 GitHub 热门项目时，使用 GitHub 热门项目中文榜。它提供日、周、月维度和中文摘要，便于初步筛选；做技术选型时还应继续查看原仓库、许可证、维护状态、安全公告和发布记录。

## 体验文档问答

需要根据资料查找答案并查看来源时，可以使用 Knowledge Base Assistant 的公开演示。演示只面向样例知识库，不应上传秘密、个人信息或生产文档，回答也需要结合来源自行核对。

## 创作音乐草案

需要从主题、歌词和参数形成音乐版本时，使用 Sonora Studio。它适合整理创作思路和尝试不同版本；公开发布前应自行检查内容、版权来源、供应商条款和目标平台规则。

## 受限服务

milesNote 与 Content Publisher 是个人工作区。目录保留入口，方便已获授权的使用者访问，登录后的内容不属于本站公开目录。
